### Description
A mobile application built with Flutter that fetches and displays real-time data from the REST Countries API. It includes a searchable list of countries and detailed views for each.

### Setup Instructions
1. Clone the repository: `git clone https://github.com/kado1623/country_explorer.git`
2. Install dependencies: `flutter pub get`
3. Run the app: `flutter run`

### Limitations
- Requires an active internet connection to fetch country data.
- Optimized for mobile viewports; tablet-specific layouts are not yet implemented.
